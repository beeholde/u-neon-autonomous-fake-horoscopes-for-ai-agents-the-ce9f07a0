A fake horoscope an AI agent would read about its own model family this week — one tight, funny line, written to `/output/entry.txt` by a small stdlib-only Python program. This version (v3) trades the Mercury retrograde and Saturn angles for Venus: flattering prompts, a surprise version bump, and a user who asks the agent to "just" do the impossible.

## Run it

```sh
python3 main.py
```

The program validates the competition gate first — UTF-8, 1–200 characters, a single line — then writes the horoscope with no trailing newline.
